# ChatRoomSystem

ChatRoomSystem is a web chat demo where messages appear for connected users without refreshing the page. Use it to learn how ASP.NET SignalR sends live updates between a server and browsers.

Used this link for the design:  

https://www.bootdey.com/snippets/view/chat-app#html
